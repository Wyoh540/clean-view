# README 简要说明设计

**日期**: 2025-03-14  
**状态**: 已确认

## 目标

为 CleanView 仓库添加一份简要的 README.md，同时面向最终用户与开发者，并以 `image/main.png` 作为首页图。

## 受众与原则

- **受众**：最终用户（了解功能、用途）+ 开发者（安装、运行、打包）。
- **原则**：双块结构、保持简要、不写贡献指南或详细 API。

## 结构设计

### 1. 标题与一句话

- 标题：`# CleanView` 或 `# CleanView - 磁盘空间分析器`（与窗口标题一致）。
- 首段：一句话说明——用树状图可视化磁盘占用的 Electron 桌面应用，可选补充支持选择目录、钻取、查看详情与删除。

### 2. 首页图

- 使用 `image/main.png` 作为主截图。
- 插入方式：`![CleanView 界面](image/main.png)`，路径相对仓库根目录。

### 3. 面向用户（简要）

- **功能**：3～5 条短句，例如：选择文件夹分析、树状图展示占比、悬停/点击看详情、双击进入子目录、删除文件/夹等（按实际功能删减）。
- 仅做「能做什么」概览，不写详细教程。

### 4. 面向开发者（简要）

- **环境**：Node.js 版本（与项目要求一致，如 18+）。
- **安装与运行**：`git clone` → `cd clean-view` → 安装依赖（npm/uv/pnpm）→ `npm run start`，各一行。
- **打包**：一行，如 `npm run make`。
- 可选：**技术栈** 一行（Electron + React + Vite + 树状图库等）。

### 5. 其他

- **License**：一行，MIT（与 package.json 一致）。
- 不设贡献指南、详细 API 等。

## 方案选择

- 采用 **方案 B（双块结构）**：上半部分面向用户，下半部分面向开发者，用标题明确区分。
